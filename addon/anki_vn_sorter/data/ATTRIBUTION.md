# Frequency data attribution

Anki VN Sorter bundles and can download frequency data derived from Jiten.
Keep this notice with redistributed add-on packages and with modified copies of
these frequency data files.

## Jiten

- Source: <https://jiten.moe/>
- Source repository: <https://github.com/Sirush/Jiten>
- Frequency-list data license: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0), <https://creativecommons.org/licenses/by-sa/4.0/>

Jiten's site states that decks, frequency lists, and derived data are licensed
under CC BY-SA 4.0. It also states that it uses dictionary data from JMdict,
JMnedict, and KANJIDIC, which are the property of the Electronic Dictionary
Research and Development Group and are used under the EDRDG license.

## Bundled data in this add-on

- `jiten_frequency_global.csv` is a bundled snapshot of Jiten's Global frequency
  list.
- `bee_frequency.zip` is Bee's Yomitan frequency dictionary, generated from
  Jiten data. The archive also includes its own `attribution.txt` and index
  metadata.

The Jiten application source code is Apache-2.0, but the frequency-list data is
CC BY-SA 4.0. Treat code and data licensing separately.
